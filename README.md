# Platform Builder

Репозиторий для **Claude Code** и **Codex**: готовая обучающая платформа плюс контракт, по которому агент собирает её под вашего эксперта.
Вы отвечаете на вопросы, агент делает структуру, дизайн, меню, продукты, тексты и выкладывает сайт.

> **Агенту:** склонируй репозиторий, подготовь окружение по [`SETUP.md`](SETUP.md) и сразу начни опрос по
> [`docs/agent-contract/WORKFLOW.md`](docs/agent-contract/WORKFLOW.md). Один вопрос за раз, с вариантами ответа.
> Новичку: [`START.md`](START.md), старт за 10 минут. Полный урок-презентация (60 слайдов со скриншотами): [`docs/lesson-presentation.pdf`](docs/lesson-presentation.pdf).

## Как это работает

1. **Эксперт и ниша ⏸**: кто преподаёт, чему, для кого, на каком языке.
2. **Структура ⏸**: сколько страниц, разделов, пунктов меню. Картинка `structure.jpg`: Минимум, Школа, Полный.
3. **Роли ⏸**: гость, оплативший, куратор, админ; задания, чаты, календарь.
4. **Продукты ⏸**: сколько курсов, цены, оплата, нужны ли КП-страницы.
5. **Дизайн ⏸**: картинки `designs-*.jpg`, 32 готовых дизайна, вариант 33 «свой», шрифты на выбор.
6. **Контент ⏸**: тексты, фото, видео, база куратора.
7. **Сервисы ⏸**: Supabase, Vercel, Resend, Gmail через коннекторы Claude; без домена или со своим доменом; оплата Kaspi или Freedom Pay. Ключи вводит владелец.
8. **Сборка**: агент меняет копию шаблона в `projects/<id>/site/` строго по файлам этапов.
9. **Проверки и выкладка ⏸**: сборка, демо, скриншоты, сторож секретов, подтверждение.

⏸ означает: агент задал вопрос и ждёт ответа. Каждый этап закрывается файлом в `projects/<id>/`, а не словами в чате.

## Что внутри

| Папка или файл | Что |
|---|---|
| `CLAUDE.md`, `AGENTS.md` | точки входа для Claude Code и Codex |
| `START.md`, `SETUP.md`, `CONTEXT.md` | старт, установка, карта «что где» |
| `docs/FROM-ZERO.md` | с нуля: Claude Code, коннекторы (GitHub, Supabase, Vercel, Resend, Gmail), выкладка без домена и с доменом |
| `docs/PAYMENTS.md` | оплата в Казахстане: Kaspi Pay вручную или Freedom Pay автоматически |
| `docs/agent-contract/` | `WORKFLOW.md` (этапы), `QUESTIONS.md` (вопросы с вариантами), `PERSONALIZATION.md` (что менять под эксперта) |
| `.claude/` | команда `/platform`, навыки, хук-сторож чтения больших файлов |
| `knowledge/` | принципы по этапам |
| `patterns/` | каталог дизайнов (`designs.json`, `CATALOG.md`) и шрифтов (`fonts.json`, `FONTS.md`), порядок применения |
| `reference/style-previews/` | картинки для выбора и их генератор |
| `studio/` | чистый шаблон платформы (React, TypeScript, Vite, Supabase, Vercel), в нём не работаем |
| `projects/_template/` | заготовки файлов этапов; `projects/<id>/` создаётся скриптом |
| `scripts/` | установка, новый проект, сторож секретов, поиск остатков образца |

## Проверки

```bash
bash scripts/check-secrets.sh                              # ключи и запрещённые файлы
bash scripts/check-leftovers.sh projects/<id>/site         # остатки образца в собранной платформе
cd projects/<id>/site && npm run build                     # сборка
cd projects/<id>/site && VITE_DEMO=1 npm run dev           # демо без базы, localhost:5173
```

## Чего здесь нет

Ключей, паролей и токенов. Личных данных эксперта-образца: телефоны заменены на `7XXXXXXXXXX`, фото и логотипы на заглушки,
база куратора на три примера. Готовых платформ учеников: у каждого свой репозиторий.

Структура контракта (этапы с паузами, файлы-замки, сторож секретов) адаптирована из проекта
[reels-pipline-automotaj](https://github.com/saint4ai/reels-pipline-automotaj), лицензия MIT. См. [`NOTICE.md`](NOTICE.md).
