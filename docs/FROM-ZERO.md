# Платформа с нуля: от пустого компьютера до сайта с учениками

Цель: владелец только регистрируется в сервисах и нажимает «Разрешить», всё остальное делает Claude Code
через коннекторы. Домен — единственное, что покупается отдельно, и он не обязателен (вариант А).

> **Агенту:** этот файл — порядок этапа 0 и этапа 7 из [`agent-contract/WORKFLOW.md`](agent-contract/WORKFLOW.md).
> Сначала проверь, какие коннекторы уже подключены, и проси владельца подключить только недостающие.
> Ключи и пароли владелец вводит сам: в окне сервиса, в `.env.local` или в Vercel. Ты их не печатаешь.

## Шаг 1. Claude Code на компьютере

1. Скачать приложение Claude: [claude.ai/download](https://claude.ai/download) (Mac или Windows), войти, подписка Pro или Max.
2. Открыть вкладку **Code**, выбрать пустую папку, например `Документы/platform`.
3. Модель: самая новая Opus, усилие high или выше.
4. Первое сообщение — из [`START.md`](../START.md): агент сам клонирует этот репозиторий и ставит Node.js, git и зависимости.

## Шаг 2. Коннекторы — чтобы Claude делал всё сам

Claude → Настройки → **Коннекторы** (Connectors) → найти сервис → «Подключить» → войти и нажать «Разрешить».

| Коннектор | Что агент делает сам | Без него |
|---|---|---|
| **GitHub** | создаёт репозиторий, сохраняет код, следит за версиями | владелец создаёт репозиторий руками |
| **Supabase** | создаёт проект базы, запускает `schema.sql` и миграции, создаёт админа, проверяет безопасность | владелец вставляет SQL в SQL Editor |
| **Vercel** | создаёт проект, подключает GitHub, переменные окружения, домен, смотрит ошибки выкладки | владелец делает всё в панели Vercel |
| **Resend** | отправитель писем, проверка домена, тестовое письмо | ключ API вставляется руками |
| **Gmail** | вариант А без домена: письма ученикам через вашу почту Gmail (пароль приложения вводите сами) | письма только через встроенную почту Supabase с лимитом |

Проверка: попросите агента «Проверь, какие коннекторы подключены, и скажи, чего не хватает».
GitHub дополнительно работает через терминал: агент сам запустит `gh auth login`, вход — в окне браузера.

## Шаг 3. Опрос и сборка

Агент ведёт по этапам 1–6 и 8 из `WORKFLOW.md`: эксперт, структура, роли, продукты, дизайн, контент, сборка.
Всё сохраняется файлами в `projects/<имя>/`.

## Шаг 4. Выкладка: два варианта

### Вариант А — без своего домена (быстрый старт, 0 ₸)

| Что | Как |
|---|---|
| Адрес сайта | `имя-проекта.vercel.app` — Vercel даёт бесплатно |
| База и вход | Supabase, бесплатный тариф |
| Письма входа и сброса пароля | встроенная почта Supabase (несколько писем в час) **или** SMTP Gmail: Supabase → Authentication → SMTP → `smtp.gmail.com`, порт 465, ваша почта и **пароль приложения** Google |
| Письма «курс открыт», рассылки | Resend без домена шлёт только на вашу почту — для учеников нужен вариант Б или Gmail |
| Оплата | ссылка Kaspi Pay у курса, подтверждение в админке (см. [`PAYMENTS.md`](PAYMENTS.md)) |

Агент делает: проект Supabase → таблицы → проект Vercel из GitHub → переменные `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`,
`SUPABASE_SERVICE_ROLE_KEY`, `SITE_URL` → Supabase → Authentication → URL Configuration: Site URL = адрес Vercel → выкладка → проверка входа.

### Вариант Б — со своим доменом (для запуска на учеников)

1. **Купить домен** (это делает владелец): ps.kz, hoster.kz (для `.kz`) или Namecheap, Cloudflare (для `.com`). 3–15 тыс. ₸ в год.
2. **Vercel** (агент): Project → Settings → Domains → добавить `моя-школа.kz`. Vercel покажет записи DNS.
3. **DNS у регистратора** (владелец вставляет, агент диктует): запись `A @ 76.76.21.21` и `CNAME www cname.vercel-dns.com`
   (точные значения — из экрана Vercel). Через 10 минут – 24 часа сайт откроется на домене, HTTPS включится сам.
4. **Resend** (агент): Domains → добавить домен → три записи DNS (SPF, DKIM, MX) владелец вставляет у регистратора → Verify.
   Потом `RESEND_FROM=Школа <hello@моя-школа.kz>` в Vercel.
5. **Supabase**: Authentication → SMTP → Resend (`smtp.resend.com`, порт 465, логин `resend`, пароль — ключ API Resend),
   отправитель `hello@моя-школа.kz`. Site URL и Redirect URLs → `https://моя-школа.kz`.
6. `SITE_URL=https://моя-школа.kz` в Vercel → Redeploy.

## Шаг 6. Финальная проверка (агент)

- `bash scripts/check-secrets.sh` — нет ключей в коде.
- Сборка `npm run build`, вход админа, регистрация тестового ученика, открытие урока, отправка задания.
- Телефон и компьютер, светлая и тёмная тема.
- Supabase → Advisors → Security: нет красных пунктов.

## Что владелец делает руками (коротко)

1. Подписка Claude и вход в приложение.
2. Регистрация в GitHub, Supabase, Vercel, Resend; «Разрешить» в окнах коннекторов.
3. Вставка ключей в `.env.local` и Vercel, если агент попросит.
4. Покупка домена и вставка записей DNS (только вариант Б).
5. Договор с платёжной системой (для онлайн-оплаты).
