# Сервисы

| Сервис | Зачем | Что владелец делает сам | Куда идёт ключ |
|---|---|---|---|
| GitHub | хранить код, запускать выкладку | создаёт аккаунт и репозиторий | не нужен |
| Supabase | база, вход, права, файлы | создаёт проект, копирует URL и anon key | `.env.local` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) |
| Supabase service role | серверные действия админа | копирует ключ | только настройки Vercel (`SUPABASE_SERVICE_ROLE_KEY`), никогда в код и git |
| Vercel | хостинг сайта и функций `api/` | импортирует репозиторий, вставляет переменные | настройки проекта |
| Resend | письма «доступ открыт» | подтверждает домен, создаёт ключ | Vercel (`RESEND_API_KEY`, `RESEND_FROM`, `SITE_URL`) |
| Google Sheets | резерв регистраций | вставляет скрипт `docs/google-sheet-apps-script.gs` | ссылка скрипта в настройках |

Порядок SQL: `supabase/RUN_ALL_migrations.sql` целиком в SQL Editor. Первый админ: строка из конца `schema.sql`, подставить почту владельца.
Агент ведёт по шагам, пароли и ключи в чат не принимает.
