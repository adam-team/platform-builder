# Банк вопросов с вариантами ответов

Формат: задаёшь один вопрос, показываешь варианты цифрами, добавляешь «свой вариант». Ответ владельца сохраняешь в файл этапа.
Тон: простыми словами, без терминов. Владелец не программист.

## Блок A. Эксперт и ниша (этап 1)

**A1. Для кого собираем платформу?**
1. Для себя, я и есть эксперт
2. Для другого человека (я делаю платформу под клиента)
3. Для команды или школы с несколькими преподавателями

**A2. Чему учим?** Свободный ответ, одной фразой. Если расплывчато, уточни: «Что ученик сможет после курса, чего не мог до него?»

**A3. Кто ученик?**
1. Новичок, начинает с нуля
2. Практик, хочет вырасти
3. Профессионал, нужна узкая специализация
4. Смешанная аудитория

**A4. Язык интерфейса?**
1. Казахский (как в шаблоне, правок по языку нет)
2. Русский (агент переводит строки интерфейса, `PERSONALIZATION.md`, раздел «Язык»)
3. Английский
4. Казахский и русский с переключателем (самый объёмный вариант, предупреди о сроках)

**A5. Название и домен?**
1. Есть название и домен
2. Название есть, домена нет
3. Пока рабочее имя, придумаем позже

**A6. Откуда стартуем?**
1. С нуля, учеников и курсов нет
2. Курсы записаны, нужна площадка
3. Уже есть ученики в чатах или на другой платформе (нужен перенос и импорт пользователей)

## Блок B. Структура (этап 2). Показываешь `structure.jpg`

**B1. Какой размер сайта?**
1. Минимум: главная, курс, вход, кабинет (4 экрана)
2. Школа: плюс услуги, бесплатные уроки, о эксперте, профиль (8-9 экранов)
3. Полный: плюс КП-страницы, новости, магазин услуг, админка с CRM

**B2. Верхнее меню сайта.** Шаблон: Басты, Курстар, Қызметтер, Тегін сабақтар. Сколько пунктов нужно (3-6) и как назвать?

**B3. Нижнее меню на телефоне.** Шаблон: 4-5 вкладок. Что в них? Максимум 5.

**B4. Главная страница, какие блоки оставить?** Мультивыбор: герой, цели/направления, об эксперте, цифры, новости, бесплатные уроки, финальный призыв.

**B5. Меню админки.** Показываешь список разделов из `src/pages/admin/adminSections.ts`. Что оставить, что скрыть, что переименовать.

## Блок C. Роли и кабинет (этап 3)

**C1. Роли.** Мультивыбор: гость (без оплаты), оплативший, куратор, админ. Минимум нужны гость и админ.

**C2. Домашние задания.**
1. Проверяет куратор вручную
2. Бот-куратор отвечает по базе знаний эксперта
3. Без проверки, только просмотр уроков

**C3. Что включить в кабинете?** Мультивыбор: чат с куратором, чат поддержки, календарь событий, уведомления, прогресс по урокам, комментарии к урокам.

**C4. Нужен ли демо-режим для показа без базы?** Да/нет.

## Блок D. Продукты (этап 4)

**D1. Сколько курсов на старте?** 1 / 2-3 / 4 и больше. По каждому спроси название, цену, старую цену, формат.

**D2. Формат курса.**
1. Запись, доступ навсегда
2. Запись, доступ на срок (спроси срок)
3. Живой поток с кураторами
4. Смешанный

**D3. Бесплатные уроки.** Нужны ли и сколько (шаблон: раздел «Тегін сабақтар» плюс форма регистрации).

**D4. Оплата.**
1. Ссылка на платёж (Kaspi Pay, Stripe, Robokassa и т.п.)
2. Оплата через менеджера в WhatsApp
3. Перевод, куратор подтверждает вручную
4. Позже, пока только записи на консультацию

**D5. КП-страницы (продающие страницы под продукт).** Сколько и для каких продуктов. В шаблоне их две, как образец.

## Блок E. Дизайн (этап 5). Показываешь `designs-A…E.jpg`, затем `fonts-1…4.jpg`

**E1. Выбор дизайна по номеру 1-32** (таблица `patterns/CATALOG.md`) **или 33: свой дизайн** (присылает PDF, скриншот, ссылку на сайт-образец, цвет бренда и шрифты).
Не знает: спроси настроение (строгий, тёплый, яркий, премиум, тёмный) и предложи 2-3 номера.
**E2. Тема:** светлая, тёмная, обе (у тёмных дизайнов одна).
**E3. Шрифты:** как в дизайне или любые из каталога (`fonts-1…4.jpg`, имя шрифта или номер листа). Интерфейс на казахском: шрифт должен содержать казахские буквы, иначе замена.
**E4. Логотип:** есть файл / сделаем текстовый знак / без логотипа.
**E5. Форма:** радиусы и тени (острые, средние, мягкие), плотность (воздушно, обычно, плотно).
**E6. Фирменные приёмы выбранного дизайна** (меню, подача карточек, см. «Особенности оформления» в `CATALOG.md`): взять или оставить стандартные.
**E7. Фото:** есть фото эксперта и обложки / фото сделаем позже (будут заглушки).

## Блок F. Контент (этап 6)

Спрашивай по одному блоку: герой, об эксперте, цифры, курсы, уроки, бесплатные уроки, видеохостинг, база куратора, политика.
По каждому три варианта: «пишу сам», «набросай ты, я поправлю», «пропустить, оставить заглушку».
Набросок агента всегда помечай `ЧЕРНОВИК` и не включай в него выдуманные цифры.

## Блок G. Сервисы (этап 7)

Спрашивай по одному: есть ли аккаунт Supabase, GitHub, Vercel, Resend. Нет: «создадим вместе, вот ссылка и три шага».
Пароли и ключи не принимай в чат, показывай, куда их вставить самому.
