# Дизайны и шрифты платформы

Здесь собрано всё, что владелец может выбрать на этапе 5: **32 готовых дизайна** (из PDF-концепций для финансового консультанта, брендбука Куралай, PERSONA,
каталога и концептов приложения подбора персонала), **вариант 33: свой дизайн** и **38 шрифтов** с проверкой казахских букв.

| Файл | Что |
|---|---|
| `designs.json` | источник данных дизайнов: номер, палитра, шрифты, радиус. Правим только его |
| `fonts.json` | источник данных шрифтов: тип, поддержка казахского, замена, пакет |
| `CATALOG.md` | таблица всех дизайнов и их фирменные приёмы (собирается автоматически) |
| `FONTS.md` | таблица всех шрифтов и порядок подключения (собирается автоматически) |
| `../reference/style-previews/designs-*.jpg` | картинки выбора дизайна с номерами |
| `../reference/style-previews/fonts-*.jpg` | образцы шрифтов на русском, казахском, английском |
| `../scripts/design-tokens.py` | печатает готовые переменные `:root`, пакеты и импорты шрифтов для выбранного номера |
| `../scripts/extract-design.py` | для варианта «свой»: достаёт цвета и шрифты из PDF, картинки или сайта |

После правки JSON пересобери картинки и таблицы: `python3 reference/style-previews/build-previews.py` (нужны Google Chrome и Pillow).

## Как показывать выбор (этап 5)

Покажи листы по порядку, каждый абсолютным путём в Markdown, чтобы владелец увидел картинку:

1. `designs-A.jpg`: дизайны для финансового консультанта, номера 1-6.
2. `designs-B.jpg`: Куралай, PERSONA, каталог, номера 7-10.
3. `designs-C1.jpg`, `designs-C2.jpg`: концепты приложения подбора персонала, часть 1, номера 11-20.
4. `designs-D.jpg`: те же концепты, часть 2, номера 21-26.
5. `designs-E.jpg`: базовые стили 27-32 и плитка **33: свой дизайн**.

Если владелец заранее называет направление (тёмный, строгий, тёплый, яркий), покажи подходящие листы и предложи 2-3 номера, не заставляй листать всё.
Затем шрифты: `fonts-1.jpg … fonts-4.jpg`. У каждого дизайна свои шрифты, но владелец вправе взять **любой шрифт для заголовков и любой для текста**.

## Как применять выбранный номер

```bash
python3 scripts/design-tokens.py 3              # дизайн номер 3
python3 scripts/design-tokens.py 3 --kk         # интерфейс на казахском: шрифты без казахских букв заменяются автоматически
python3 scripts/design-tokens.py 3 --with-dark  # для светлого дизайна добавить черновик тёмной темы
python3 scripts/design-tokens.py list           # список номеров
python3 scripts/design-tokens.py projects/<id>/design.custom.json   # свой дизайн (вариант 33)
```

Скрипт ничего не меняет: он печатает блок для `src/styles.css`, команду `npm install @fontsource/...` и импорты для `src/main.tsx`. Дальше:

1. Подставь переменные в `:root` в `projects/<id>/site/src/styles.css`. Не раскидывай hex по компонентам.
2. Светлый дизайн: блок `@media (prefers-color-scheme: dark)` из шаблона удали (он зелёный и не подходит) или замени черновиком `--with-dark`.
   Тёмный дизайн: значения кладутся в `:root`, блок `@media` удаляется.
3. Поставь шрифты и добавь импорты в `src/main.tsx`. Убери из `package.json` пакеты шрифтов, которые больше не нужны
   (КП-страницы шаблона используют `src/lib/kpFonts.ts`: `cormorant` и `onest`; если КП-страницы не нужны, убери их вместе с маршрутами).
4. Заголовки: добавь правило из вывода скрипта `h1, h2, h3, h4 { font-family: var(--font-display); }`.
5. Замени цвет текста на кнопке бренда: у части дизайнов он тёмный (`--on-brand`). Найди кнопки с `color: #fff` на фоне `--brand`.
6. Контраст текста на бренд-кнопке не ниже 4,5:1. Скрипт предупредит, если ниже.
7. Открой страницу с казахским текстом и проверь глазами `ә ғ қ ң ө ұ ү һ і`.
8. Запиши в `DESIGN.md`: номер, итоговые hex, шрифты, замены для казахского, и какие «фирменные приёмы» (`CATALOG.md`) владелец попросил добавить.

## Казахский язык и шрифты

Проверено по реальным файлам шрифтов. **Нет казахских букв** в `Manrope` (нет `ә ғ қ ң ұ`), `Unbounded` (нет всех), `JetBrains Mono`
(нет `ә ғ қ ң ұ һ`), `Tenor Sans` и `Jost`. В `CATALOG.md` у таких дизайнов в колонке KK стоит «→ шрифт»: для казахского интерфейса применяй
с `--kk`, скрипт подставит замену (`Manrope` → `Onest`, `Unbounded` → `Geologica`, `JetBrains Mono` → `IBM Plex Mono`,
`Tenor Sans` → `Golos Text`, `Jost` → `Onest`). Если интерфейс русский, замена не нужна и оригинальный шрифт остаётся.

Сомневаешься в другом шрифте, проверь его: `python3 scripts/extract-design.py --kk-check "Имя шрифта"` (нужен `pip install fonttools`).

## Свой дизайн (вариант 33)

Последний вариант: ученик присылает собственный дизайн. Порядок:

1. Спроси, что есть: PDF или скриншоты дизайна, ссылка на сайт-образец, фирменный цвет, названия шрифтов, логотип. Хватит и одного пункта.
2. Положи материалы в `projects/<id>/design-input/` (эта папка в `.gitignore`, материалы клиента в репозиторий не попадают).
3. Достань цвета и шрифты:
   ```bash
   python3 scripts/extract-design.py projects/<id>/design-input/дизайн.pdf
   python3 scripts/extract-design.py https://сайт-образец.kz
   ```
4. Покажи владельцу черновик ролей (фон, текст, бренд, акцент) и спроси «Так?». Цвета подгоняются руками: скрипт даёт только черновик.
5. Шрифты: найди в `FONTS.md`. Нет в каталоге: проверь на Google Fonts и казахские буквы (`--kk-check`), найди пакет `@fontsource/<имя>`.
   Платный или собственный шрифт не вставляй без файла и лицензии от владельца.
6. Собери `projects/<id>/design.custom.json` по образцу записи из `designs.json` (поля: `name`, `bg`, `surface`, `text`, `muted`, `brand`,
   `on_brand`, `accent`, `radius`, `fh`, `fb`, `dark`; остальное заполнится само) и прогони `python3 scripts/design-tokens.py projects/<id>/design.custom.json`.
   Шрифтов нет в `fonts.json`: добавь их туда (`name`, `pkg`, `type`, `kk`, `cyr`, `weights`, `note`, `kk_alt`).
7. Запиши в `DESIGN.md` «вариант 33, свой», источники (файл, ссылка) и итоговые значения.
8. Чужой дизайн копируем по цветам, шрифтам и настроению. Логотипы, тексты и картинки чужого бренда не берём.

## Что запрещено

- Раскидывать hex-цвета по компонентам. Только переменные.
- Подключать шрифты ссылкой на внешний сервер в продакшене: пакеты `@fontsource` отдаются со своего сайта.
- Менять структуру карточек и сетку под стиль без просьбы владельца. Стиль это цвет, шрифт, радиус, плотность.
  Фирменные приёмы (тип меню, подача карточек) из `CATALOG.md` ставятся только если владелец попросил, запись в `DECISIONS.md`.
- Использовать фото, имена и тексты из примеров (концепты для финансиста, концепты подбора персонала). В каталоге взяты только палитры, шрифты и настроение.
