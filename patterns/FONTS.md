# Каталог шрифтов

Файл собирается скриптом `reference/style-previews/build-previews.py` из `patterns/fonts.json`. Руками не править.

Казахские буквы проверены по реальным файлам шрифтов (Google Fonts): `ә ғ қ ң ө ұ ү һ і` строчные и заглавные. Образцы: `reference/style-previews/fonts-*.jpg`.

Все шрифты бесплатные (лицензия SIL OFL или Apache 2.0), подключаются пакетом `@fontsource/...` и отдаются со своего сайта.

**Важно про казахский.** `Manrope`, `Unbounded`, `JetBrains Mono`, `Tenor Sans` и `Jost` не содержат казахских букв (или части из них): браузер подставит запасной шрифт, и текст будет выглядеть неровно. Если интерфейс на казахском, берётся замена из колонки «Замена для казахского».

## Как подключить шрифт

```bash
cd projects/<id>/site
npm install @fontsource/<имя>
```

В `src/main.tsx`: `import '@fontsource/<имя>/400.css'` (и нужные начертания 500, 600, 700). Имя в `--font` в `src/styles.css`. Пара «заголовки / текст» берётся из выбранного дизайна. Ненужные пакеты предыдущих шрифтов убрать из `package.json`.
