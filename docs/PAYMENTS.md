# Оплата курсов в Казахстане

В платформе два режима. Переключаются одной переменной `VITE_PAYMENT_PROVIDER` в Vercel.

| | Ручной: Kaspi Pay | Автоматический: Freedom Pay |
|---|---|---|
| Когда | сразу, без договоров | после подключения магазина в Freedom Pay |
| Как платит ученик | по ссылке Kaspi Pay (счёт/QR) | на странице Freedom Pay: карта, Kaspi QR и другие способы |
| Кто открывает курс | админ: Админка → Продажи → «Подтвердить» | платформа сама, через секунды после оплаты |
| Переменная | `VITE_PAYMENT_PROVIDER` пусто или `kaspi` | `VITE_PAYMENT_PROVIDER=freedom` |
| Код | `studio/src/pages/CoursePage.tsx` (`buy`) | `studio/api/pay-create.ts`, `studio/api/pay-result.ts`, `studio/api/_lib/freedompay.ts` |

## Режим 1. Kaspi Pay вручную

1. Kaspi Pay для бизнеса → создать ссылку на оплату (или счёт) на сумму курса.
2. Админка → Обучение → курс → поле «Ссылка на оплату» (`payment_url`) и «Цена».
3. Ученик нажимает «Купить курс» → в «Продажах» появляется заявка, открывается ссылка Kaspi.
4. Деньги пришли → админ нажимает «Подтвердить» → курс открыт (функция `confirm_payment`).

## Режим 2. Freedom Pay автоматически

1. Подать заявку на [freedompay.kz](https://freedompay.kz) (ИП или ТОО), получить в кабинете магазина
   **ID магазина** (merchant id) и **секретный ключ** (платёжный пароль).
2. В Vercel → Settings → Environment Variables (агент через коннектор, значения вставляет владелец):
   - `VITE_PAYMENT_PROVIDER=freedom`
   - `FREEDOM_MERCHANT_ID=…`
   - `FREEDOM_SECRET_KEY=…` (секрет, только в Vercel)
   - `FREEDOM_TESTING=1` — пока тестируете; удалить перед запуском
   - `SUPABASE_SERVICE_ROLE_KEY`, `SITE_URL` — уже должны быть
3. Redeploy. У курса должна быть указана **цена**.
4. Тест: купить курс тестовой картой из документации Freedom Pay → курс открылся, в «Продажах» статус «оплачено».

Как это работает:

```
Ученик → «Купить курс» → /api/pay-create (цену берёт из базы, создаёт заявку и платёж Freedom Pay)
       → страница оплаты Freedom Pay → оплата
Freedom Pay → /api/pay-result (проверка подписи и суммы) → confirm_payment → курс открыт
Ученик возвращается на /course/<id>?paid=1
```

Защита: подпись `pg_sig` (MD5 по правилам Freedom Pay) проверяется у каждого уведомления, сумма сверяется с заявкой,
повторные уведомления не открывают курс дважды, секретный ключ есть только на сервере.

## Другие провайдеры

Halyk ePay, CloudPayments, Robokassa подключаются так же: новый файл в `studio/api/_lib/` с подписью провайдера
и пара `pay-create` / `pay-result`. Попросите агента: «Подключи оплату <провайдер> по образцу Freedom Pay в docs/PAYMENTS.md».
